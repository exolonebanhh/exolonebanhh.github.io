Overview

Maison Mone is a booking & management platform connecting clients with professional makeup artists (MUAs) for weddings, parties, and photoshoots. As Presales Engineer I took an auto-generated Figma Make prototype and turned it into a credible, demoable product — auditing it against the consultant backlog, fixing critical bugs, extending it with new features, and packaging the result into standalone demos that run anywhere.

Backlog Audit

Audited the source code against a 27-item consultant product backlog, categorizing every item with file-and-line evidence:

  • 3 items meeting acceptance criteria, 10 partially built, 7 not built at all, 6 pure documents, 1 mixed.
  • Core MVP focus: which of the 10 flagged items blocked a credible demo — and which could wait.
  • Delivered as a full audit report comparing backlog expectations against actual prototype behavior.

Critical Bug Fixes

  • Fixed a stuck settlement flow that dead-ended MUA payouts.
  • Fixed inconsistent down-payment (DP) amounts across screens.
  • Fixed chat opening the wrong MUA conversation.
  • Shipped as a reviewable patch: 8 files, +395 / −31 lines, applied to a clean checkout of the original source.

Customer Service Module

Designed and built a customer service feature where the CS authority boundary is enforced at the interface level, not just by policy text.

  • Two new screens: customer Help Center (ticket categories, tracking) and a CS Console (ticket queue + actions).
  • Three authority tiers — full authority, mediation & escalation, and out-of-scope — defined in one config file (csScope.ts) as the single source of truth.
  • Out-of-scope categories render no action buttons at all: "why can't CS refund off-platform payments?" is answered in the code.

Core Prototype Features

  • Booking flow with down payments, escrow, and two-way chat between customers and MUAs.
  • Separate dashboards for customers and MUAs, each screen reachable via two-way hash routing (#/chat, #/mua-dashboard, …).
  • Branded design system: rose/pink #d0356f + warm cream #fdf8f5, Poppins & Quicksand typography, CSS micro-animations.

Clever Detail

Bundled the React 19 application, Tailwind styles, and Base64-encoded image assets into single standalone HTML files (≈2.1 MB each) — one stable demo for presentations and one experimental build with the CS module. Both run offline from a double-click, built specifically for client demonstrations and stakeholder testing.

Honest scope: this is a presales prototype — there is no backend yet, and data resets on refresh. The value delivered was certainty: stakeholders saw exactly what the product could do, what it couldn't yet, and what building it would take.
