Overview

An interactive front-end prototype for a marketplace connecting clients with professional makeup artists (MUAs) for weddings, parties, and photoshoots. The prototype features verified MUA profiles, scheduling capabilities, and a customer service module — designed so stakeholders could feel the product before a single backend was built.

Design System

  • Responsive interface using a mobile-first approach with Tailwind CSS.
  • Custom branded color palette — rose/pink #d0356f paired with warm cream #fdf8f5.
  • Google Fonts typography: Poppins, Quicksand, and Great Vibes.
  • CSS micro-animations, including fadeInUp, scaleIn, and petal-drift.

Key Features

  • Verified MUA profiles with portfolio presentation.
  • Scheduling capabilities for bookings across event types.
  • Integrated customer service module.

Clever Detail

Bundled the React 19 application, styling, and Base64-encoded image assets into a single standalone HTML prototype — the whole product experience shipped as one file that runs anywhere, built specifically to facilitate client demonstrations and stakeholder testing.
