Overview

An end-to-end enterprise procurement application covering the complete purchasing cycle — Purchase Requests, approvals, Purchase Orders, receiving and QC, through invoicing. The application supports 4 user roles (Admin, Manager, Staff, and Viewer), serves content in 3 languages, and runs on a hardened production stack.

Security Audit & Hardening

Remediated critical vulnerabilities by securing over 155 previously unauthenticated API endpoints through a global JWT authentication gate (before_request) and role-based access control across all four roles.

Core Workflow & Database

  • Built an auditable approval workflow with approver identity and timestamp logging, mandatory rejection reasons, and immutable statuses.
  • Resolved legacy PostgreSQL schema issues through idempotent SQL migrations, restoring the end-to-end workflow from PR to invoice.
  • 172 REST API endpoints · 36 PostgreSQL tables.

Testing & Deployment

  • Established a staging-to-production deployment pipeline featuring automated backups, schema migrations, and checksum verification.
  • Validated the application with an automated API test suite — 33 assertions passing at 100%, along with browser DOM verification.
  • Systematically diagnosed and resolved a production DNS outage on Cloudflare.

Localization

Translated approximately 3,000 lines of mixed Chinese-language UI into English using a custom phrase-dictionary pipeline.
